# 📚 E-Lab — Online Library Management System

Welcome to **E-Lab**, a modern and user-friendly online library management system built to streamline book browsing, borrowing, and administration for students, librarians, and library staff.

---

## 🌟 Project Overview

E-Lab is designed to provide a clean, responsive interface for managing library operations. It includes pages for:

- **Home / Landing page** with quick access to library sections
- **Book listings** and detail views for each title
- **Admin dashboard** for managing books and users
- **Library search and navigation** functionality

This project is ideal for small libraries, school library systems, or personal book collections.

---

## 🧩 Features

| Feature                  | Description                                                         |
| ------------------------ | ------------------------------------------------------------------- |
| 📖 Book catalog          | Browse available titles and view detailed information for each book |
| 🧾 Admin interface       | Manage library content and perform administrative tasks             |
| 🎨 Responsive design     | Works well on desktop and mobile screens                            |
| 🔎 Search-ready          | Easy-to-read layout for finding books and library resources         |
| 📄 Simple static web app | Built with HTML, CSS, and JavaScript for fast local deployment      |

---

## 🚀 Included Files

- `index.html` — main landing/home page
- `books.html` — library book list page
- `book-details.html` — individual book detail page
- `admin.html` — administration access page
- `dashboard.html` — admin dashboard view
- `script.js` — JavaScript functionality for page behavior
- `style.css` — global styling and responsive layout
- `library.avif` — library image asset
